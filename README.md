# Python Assignment

This repository contains two Python programs completed as part of my Python programming assignment.

## 📁 Projects

### 1. Student Grade Calculator
- Takes student name and marks for three subjects.
- Calculates total and average marks.
- Determines grade using conditional statements.
- Displays results using f-strings.

### 2. Simple Shopping Cart
- Takes customer name and three product details.
- Calculates subtotal.
- Applies discounts based on purchase amount.
- Calculates final total using f-strings.

## 🛠️ Technologies Used
- Python
- Conditional Statements (if-elif-else)
- User Input
- Arithmetic Operations
- f-Strings
